# Semester 2 Intentions (Optional but useful)

## What we’ll carry forward

- Pebble partials for list/view/edit and pagination.
- HTMX + PRG dual-path pattern with shared IDs and live regions.
- Backlog-first, evidence-driven workflow (crit → backlog → fix → verify).

## Risks to tackle early

- Focus management in multi-step flows (wizard/confirm pages).
- No-JS delete confirmation pattern to avoid destructive errors.
- Screen reader parity across platforms (VoiceOver, NVDA, Orca).
- Contrast regressions when theming (2.4.11 focus appearance).

## Guest lectures / project slots we want to see

- WCAG 2.2 focus appearance (2.4.11) with practical colour tooling.
- Server-first accessibility patterns for modals/confirmation (HTMX + no-JS).
- Automated no-JS testing with Playwright/CI.
